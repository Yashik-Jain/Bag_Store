#  Bag Store

A backend-focused e-commerce application developed using **Node.js**, **Express**, and **MongoDB**. The project demonstrates user authentication, product management, and secure routing for an online shopping experience.

---

##  Features

- User Registration & Login
- JWT Authentication
- Product Management
- MongoDB Integration
- Secure Password Encryption
- Server-side Rendering

---

##  Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- EJS

---

##  Learning Outcomes

- Backend Development
- REST APIs
- Authentication
- MongoDB CRUD
- Express Middleware

---

##  Future Improvements

- Shopping Cart

- Product Categories
- Wishlist

##  Installation

```bash
git clone https://github.com/Yashik-Jain/Bag_Store.git

cd bag-store

npm install

npm start
```
